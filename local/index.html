MONO Design System

A framework-agnostic utility library for SASS

MONO helps to manage your styles between Figma and your code. It provides access to Figma Variables and a set of useful tools to help you reflect the designs easier in your code.

Features

MONO is not generating any CSS code, instead it provides you access to Figma Variables and set of useful tools to help you reflect the designs easier in your code.

Built with modern SASS features and best practices in mind.
